# Zakah Calculator (JS Mini Project)

## Description

This is a simple JavaScript-based Zakah calculator. It takes a monetary amount as input and calculates the Zakah (2.5%) due. The project also includes a light/dark mode toggle for better user experience.

## Features

- Calculates 2.5% Zakah from the entered amount.
- Displays appropriate messages for invalid inputs.
- Light/Dark mode toggle.
- Built with Bootstrap for styling.

## How to Run

Clone the repository:

```bash
git clone https://github.com/TesterXXXX/zakah-calculator.git
```
